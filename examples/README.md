# Local integration examples

`shared-evidence/` contains reduced booking and publication fixtures, not full applications. Use [the current 1.1 quickstart](../docs/QUICKSTART.md). It separates source-checkout execution, installed-package execution and the historical 0.7 kit template.

Examples execute real local workflow stages with sample data/in-memory storage. They do not require a model, cloud account, payment vendor or credentials. They teach boundaries and verify receipts, not production hosting or general benchmark performance.
